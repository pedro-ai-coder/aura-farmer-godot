# M0.1 hero entrance candidate

## Ideal State

The selected hero walks into the selected arena, owns a recognizable signature beat, then hands the player the same legal opening state as an ordinary run.

## Criteria and probes

| ID | Criterion | Probe |
| --- | --- | --- |
| E1 | Four composed shots use the selected hero and map, with distinct stages and an accessible Skip. | Render both arenas and check every appearance/map combination. |
| E2 | Completion and Skip initialize gameplay once with the same spawn, clock, RNG, score entry and kit as the existing path. | Compare both handoffs with a direct start across the roster. |
| E3 | Reduced Motion uses fixed compositions and a static countdown. Retry bypasses the entrance and return to Garage works. | Run dedicated lifecycle and rendering checks. |
| E4 | Candidate footage, asset provenance, Web ZIP and protected preview are pinned to the same revision. | Verify archive contents, preview manifest and browser execution. |

## Anti-criteria

This feature does not alter gameplay rules, stable asset identities, Wave Music V1, Flex, the Big Hater or canonical approval.
