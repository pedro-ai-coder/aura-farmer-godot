# M0 cinematics candidate

## Ideal State

The first enemy, viral escalation and Big Hater entrance give an ordinary run a recognizable CLUTCHPUNKS rhythm, with an immediate emotional payoff at results.

## Vision

The existing Feedverse wave language and coral Big Hater treatment carry from the first post to the final confrontation. Compact cards let the player keep moving during every combat cue.

## Criteria and test strategy

| ID | Criterion | Falsifier |
| --- | --- | --- |
| C1 | Intro, first enemy, Wave 3 and boss warning read as distinct beats. | A focused run fixture misses a trigger, sees it replay, or sees a card during a modal. |
| C2 | Big Hater retains the current audiovisual cues and gets a stronger title accent. Victory and defeat read immediately with existing results actions. | Boss or outcome fixture changes spawn/reveal timing, audio hooks, or available actions. |
| C3 | Reduced Motion uses static cards and skips the defeat motion. | Reduced Motion fixture returns moving geometry or shows the defeat accent. |
| C4 | A SHA-pinned Web preview and one draft PR deliver the candidate. | Export fails, the build cannot start in a browser, or preview/PR references cannot be verified. |

## Anti-criteria

The diff changes simulation, combat audio, Flex, progression, accepted art provenance or production configuration.
