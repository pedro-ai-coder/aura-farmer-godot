# Licensed Inter UI resources

Source: Google Fonts `ofl/inter` at pinned commit `0b58fb370093f9a9f4ff785d94405710b79de67c`, originating from the Inter Project. Redistributed under the included SIL Open Font License 1.1. No Reserved Font Name is listed by this source license.

These are static instances of the approved Inter family: Medium 500 body, SemiBold 600 numbers, Black 900 actions, Display optical-size 32 / Black 900 titles. A Latin/punctuation/UI-symbol subset reduces the Web payload; uncovered scripts use Godot's fallback. Preserve tabular-number OpenType features. This is not a claim of full localization coverage.

`manifest.json` records source and committed SHA-256 values. `scripts/build_inter_fonts.py` documents the derivation using fonttools; builds use the committed resources and need no font download, credentials or paid service. The font files are not extracted from concept artwork.
