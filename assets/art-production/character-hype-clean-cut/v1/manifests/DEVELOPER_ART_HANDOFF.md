# Developer Art Handoff — Icon Batch 01

- The files in this directory are production candidates. None is wired to a scene, script, resource, or gameplay catalogue.
- Use each 256 px PNG as the standard icon source where a single raster is required; 64/32 px files are review exports.
- V5 SVG candidates remain editable original sources. Touch Grass Clean Cut v2 is raster-only; do not treat the V5 SVG as its source.
- No rarity colors or UI frames are baked into icon art. Apply labels, rarity, selection and disabled states in the development layer.
- Use GDD §8 for weapon identity and §9 for passive identity/effects. Visual reference boards do not override GDD values or names.
- Validate intended card/HUD presentation separately in Godot before runtime use.
