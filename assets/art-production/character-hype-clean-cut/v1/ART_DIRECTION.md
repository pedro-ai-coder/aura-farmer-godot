# Character Hype Broadcast — Clean Cut / Icon Direction

- Hero-first, authored arcade identity; bold readable silhouettes and less visual noise.
- Icons use one dominant object, compact two-tone shading, controlled ink outlines, and transparent square canvases.
- Retain Aura Farmer object identities and canonical GDD names. Do not copy obsolete screen labels, stats, abilities, or timings from visual mockups.
- No rarity trim, card panel, micro-text, generic glow, or decorative sparkle baked into icon masters.
- Keep individual source candidates untouched; refinements use new filenames and remain `PRODUCTION_CANDIDATE`.
- Icon target: 256 px master, transparent alpha, inspect at 64 and 32 px.

Palette cue from V5: ink `#253449`, deep ink `#13233A`, paper `#F7EDCD`, gold `#F8C45F`, sky `#4EA3FF`, coral `#E57461`, teal `#6EAAB0`, magenta `#F04BA5`, violet `#A66BFF`, healing green `#78C85C`.
