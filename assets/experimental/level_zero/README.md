`128948546f5b49f126e707445f5334ebaeea5ae7`, three original creator-uploaded PNG hashes.

before importing or launching this experimental scene. The build script runs
it automatically for Web. All three original SHA256 hashes/dimensions must
match. None of these assets is final approved art.
