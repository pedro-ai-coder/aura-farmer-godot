# Big Hater V1 audio candidates

Original CLUTCHPUNKS project contributions made for this candidate. The source is `scripts/render_big_hater_audio.py`. It uses elementary oscillators, an authored four-bar pattern and seeded noise. No recordings, sample packs, external music, third-party compositions or voice sources were used.

Run `python scripts/render_big_hater_audio.py` from the repository root to regenerate the mono 24 kHz, 16-bit PCM WAV masters. Runtime playback uses Godot's existing Master volume and mute preferences.
